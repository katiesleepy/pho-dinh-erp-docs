# Ký hiệu sơ đồ và thuật ngữ

## Ký hiệu trong sơ đồ quy trình

Các sơ đồ quy trình trong tài liệu BRD của Arito dùng bộ ký hiệu sau:

| Ký hiệu | Ý nghĩa |
|---|---|
| **System processing** | Thực hiện trên hệ thống |
| **Decision making** | Lựa chọn, ra quyết định |
| **Subprocess** | Tham chiếu sang quy trình chi tiết khác |
| **Start / End process** | Bắt đầu / kết thúc quy trình |
| **Documents** | Tài liệu, phiếu in đính kèm |
| **Manually Task** | Thực hiện bên ngoài hệ thống |
| **Connector** | Kết nối các tác vụ |

Mỗi bước trong bảng mô tả quy trình đều theo cấu trúc **Đầu vào → Thực hiện → Đầu ra**.
